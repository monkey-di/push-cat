# Обновление карт контента

Пройтись по хранилищу и актуализировать MOC-файлы в `Карты контента/`.

## Процесс

1. **Просканировать хранилище**
   - Найти все заметки во всех подкаталогах `Заметки/`
   - Найти все существующие MOC в `Карты контента/`

2. **Для каждого MOC**
   - Проверить: все ли заметки по теме в нём упомянуты?
   - Есть ли мёртвые ссылки на удалённые/переименованные заметки?
   - Актуальна ли структура и группировка?

3. **Найти осиротевшие заметки**
   - Заметки, не упомянутые ни в одном MOC
   - Предложить: добавить в существующий MOC или создать новый?

4. **Определить нужны ли новые MOC**
   - Если по теме накопилось 5+ заметок без MOC — предложить создать
   - Не создавать MOC ради одной-двух заметок

5. **Обновить Home.md**
   - Добавить ссылки на новые MOC если появились

## Правила

- Не создавать MOC без необходимости — только когда реально тесно
- Спрашивать перед созданием нового MOC
- Не трогать содержимое заметок, только карты и ссылки
