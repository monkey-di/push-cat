# Разбор Ящика квантовой запутанности

Разобрать хаос из `Ящик квантовой запутанности/` — рассортировать, связать, выкинуть лишнее.

## Процесс

1. **Просканировать**
   - Список всех файлов в Ящике
   - Прочитать содержимое каждого

2. **Определить тип каждого элемента**
   - Это задача? → `Дела/Входящие/`
   - Это знание/идея? → `Заметки/<тема>/`
   - Это ссылка/статья для изучения? → оставить в Ящике с пометкой или переместить в `Заметки/`
   - Мусор? → удалить
   - Непонятно? → спросить

3. **Для каждого элемента**
   ```
   Файл: [имя]
   Тип: [что это]
   Куда: [куда переместить]
   Почему: [коротко]
   Связи: [с чем связано в хранилище]
   ```

4. **Найти паттерны**
   - Общие темы среди элементов
   - Что можно объединить
   - Что с чем связано

## Правила

- Не переусложнять — если непонятно куда, лучше спросить
- Не всё нужно сохранять — мусор это нормально
- Искать связи с существующими заметками
- Если по теме нет подкаталога в `Заметки/` и элементов по ней мало — создавать не надо, кинуть в ближайший подходящий
