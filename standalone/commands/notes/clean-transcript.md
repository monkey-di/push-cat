# Очистка транскрипта

Превратить сырой транскрипт (субтитры YouTube, расшифровку аудио и т.д.) в читаемый текст.

## Что делать

1. Прочитать исходный файл целиком
2. Убрать мусор: `[музыка]`, `>>`, служебные метки, обрывки фраз
3. Склеить разорванные предложения (субтитры рвут текст по таймкодам)
4. Разбить на логические разделы с заголовками (если в тексте несколько тем)
5. Исправить очевидные ошибки распознавания речи (имена, термины, аббревиатуры)
6. Сохранить метаданные из шапки (источник, дата, video ID)
7. Записать результат в тот же файл или рядом (спросить)

## Чего не делать

- Не переписывать авторский текст — сохранять стиль и подачу оригинала
- Не добавлять отсебятины, комментариев или пояснений
- Не сокращать содержание, только убирать технический мусор
- Не менять порядок изложения

## Формат результата

```markdown
# [Название]

**Источник:** [url]
**Сохранено:** [дата]

---

## [Первая тема/раздел]

[Чистый текст]

## [Вторая тема/раздел]

[Чистый текст]
```
